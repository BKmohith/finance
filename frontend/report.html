1. Executive Summary

Indian micro-retailers (kirana dukandaars) form the commercial backbone of India's economy, accounting for over $800B in annual trade. Yet, over 68% of micro-retail failures stem from cash-flow miscalculations, bounced distributor cheques, and uncollected customer credit (Udhaar).

The Fundamental Flaw in Existing Solutions: Traditional ERPs demand hours of complex desktop data entry that exhausted dukandaars refuse to use. Meanwhile, modern UPI soundboxes announce payments ("₹300 received") but capture zero SKU basket metadata, creating a fatal blindspot that prevents inventory depletion or profit margin defense.

Sahayak (सहायक) bridges this gap through an ambient, multi-agent architecture that integrates effortlessly into merchants' daily habits:

  • Frictionless Ingestion: Dot-matrix paper bills captured via smartphone camera, shorthand counter text, vernacular voice notes in Hindi/Kannada, and rapid keyboard POS.
  • 100% Deterministic Accounting: Eliminates LLM financial hallucination by running all balances, FIFO inventory depletion, and price comparison through pure PostgreSQL SQL triggers with Row-Level Security (RLS).
  • Proactive Financial Intelligence: Warns dukandaars of wholesale price hikes, projects a 15-day forward cash trajectory, and prevents bounced cheques before they happen.

4. The 7 Autonomous Agents in Depth

Agent Name Underlying Engine Primary Responsibility Core Output
Agent 1: Margin-Guard Pure SQL Trigger Detects wholesale distributor price hikes >3%. Calibrated shelf MRP recommendation to defend gross profit margin.
Agent 2: Dead-Capital Hunter PostgreSQL Ledger Tracks shelf stock batches and capital turnover. Flags slow-moving SKUs with >30 days locked capital.
Agent 3: Liquidity & Khata Double-Entry SQL Manages customer receivables and Udhaar limits. Dynamic repayment reliability tiers (A: 90%, B: 70%, C: 20%).
Agent 4: FIFO Depletion Transactional SQL Depletes stock from oldest active batch on sale. Guarantees zero negative inventory and low-stock alerts.
Agent 5: 15-Day Cash Simulator NumPy Time-Series Forecasts daily cash runway against credit terms. Early warning alerts before supplier cheques bounce.
Agent 6: 10:15 PM Closing Debrief Gemini Flash + Sarvam Summarizes daily financial performance at closing. Warm vernacular audio note in Hindi/Kannada to the owner.
Agent 7: What-If Stress-Tester Conversational LLM Simulates revenue slumps, Khata lag, and shocks. Impact trajectory and top 3 ranked corrective measures.
